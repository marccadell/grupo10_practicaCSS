Traducción de estilos en CSS:

Replicamos el sistema de Figma mediante variables en :root para mantener coherencia en toda la web

                        
    :root {
        --color-primario: #8E442D;    /* Marrón café: botones y activos */
        --color-fondo: #FFFFFF;       /* Fondo limpio minimalista */
        --color-secundario: #F7F4F0;  /* Crema suave: bloques y selectores */
        --color-texto: #1A1A1A;       /* Alto contraste para lectura */
        --color-error: #E55B51;       /* Alerta: horario no disponible */
        --color-exito: #4CAF50;       /* Confirmación de pedido */
        --fuente-base: 'Inter', Arial, sans-serif;
    }

    body {
        font-family: var(--fuente-base);
        background-color: var(--color-fondo);
        color: var(--color-texto);
    }

Tipografía

  • Fuente sans-serif (Inter): elegida por su alta legibilidad en pantallas móviles y en proyector.
  • Jerarquía clara: contraste de pesos y tamaños para destacar títulos, precios y acciones principales.

Paleta de colores

  • Identidad y minimalismo: marrón café (#8E442D) para los CTA sobre fondos neutros (#FFFFFF y #F7F4F0).
  • Colores semánticos: verde para confirmar el pedido y rojo para avisar de errores de horario.
