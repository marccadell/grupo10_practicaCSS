Elemento con clase aplicada y estilo

Product Card del catálogo de TecnoCafé.

                        
    /* Contenedor Card */
    .producto-card {
        background-color: #FFFFFF;
        border: 1px solid #EAEAEA;
        border-radius: 16px;
        padding: 16px;
        display: flex;
        flex-direction: column;
        gap: 8px;
        box-shadow: 0 2px 6px rgba(0, 0, 0, 0.05);
    }

Atributo utilizado

  • Usamos un elemento class (.producto-card), atributo global en HTML y no un ID o etiqueta (tag).
  • Al ser una clase reutilizable, permite aplicar el mismo estilo en todos los productos.

Aplicación en el HTML

  • Se aplica a cada etiqueta (<li>) dentro del contenedor padre.
