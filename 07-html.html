Estructura semántica base antes de aplicar CSS.

                        
    <!-- Figma: 01_Inicio -->
    <header>
    <h1>TecnoCafé</h1>
    <label for="buscar">Buscar productos:</label>
    <input id="buscar" type="search" placeholder="Buscar productos..." />
    </header>
    <main>
    <h2>Productos destacados</h2>
    <ul>
        <li>
        <img src="images/croissant.jpg" alt="Croissant de mantequilla" width="150" />
        <h3>Croissant - 1,80 €</h3>
        <a href="02_detalle.html">Ver producto</a>
        </li>
    </ul>
    </main>

Semántica y trazabilidad

  • Comentario inicial (<!-- Figma: 01_Inicio -->) que enlaza el código con el prototipo.
  • Etiquetas semánticas (<header>, <main>, <ul>) y jerarquía estricta con un único <h1>.

Accesibilidad y navegación

  • Buscador accesible mediante <label for> e imágenes con atributo alt descriptivo.
  • Flujo completo navegable solo con enlaces relativos (<a href>) sin CSS ni JavaScript.
